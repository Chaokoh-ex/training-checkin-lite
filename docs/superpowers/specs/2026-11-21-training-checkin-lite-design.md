# เว็บเช็คชื่ออบรม (ตัวเรียบ) — Design

วันที่: 2026-11-21
สถานะ: รออนุมัติ

## เป้าหมายและเหตุผล
ทำเว็บเช็คชื่ออบรมตัวใหม่ แยกจาก `Chaokoh-ex/training-checkin` เดิม ให้ **เรียบกว่าเดิม**
ผู้เข้าอบรมสแกน QR ด้วยมือถือตัวเอง → แตะชื่อตัวเอง → เสร็จ
แอดมินเตรียมรายชื่อล่วงหน้า และดูได้ว่าใครมา/ยังไม่มา รองรับการอบรมหลายครั้งในเว็บเดียว

## Goals
- ผู้เข้าอบรม: ไม่ต้องล็อกอิน ไม่ต้องกรอก ไม่ต้องเซ็น — แค่เลือกชื่อตัวเอง
- แอดมิน: สร้างการอบรม (หัวข้อ, วันที่, รายชื่อ) ได้หลายครั้ง แต่ละครั้งมี QR ของตัวเอง เก็บประวัติไว้
- แอดมินเห็นยอด มา/ยังไม่มา และเวลาที่เช็คชื่อ

## Non-goals
- ลายเซ็น, รหัสพนักงาน, แผนก
- ยืนยันตัวตนผู้เข้าอบรม (ใครแตะชื่อแทนกันได้ — ยอมรับได้)
- หน้าดูอย่างเดียวสำหรับผู้ตรวจ (มีในตัวเดิม ตัวนี้ตัดออก)

## Anti-goals
- ซับซ้อนเท่าหรือมากกว่าตัวเดิม
- ผู้เข้าอบรมต้องทำเกิน 2 แตะ

## แนวทางที่พิจารณา
- **A. Google Sheet + Apps Script** — เรียบที่สุดฝั่งแอดมิน (ดูผลในชีตได้เลย) แต่หน้าเว็บช้าและมีแถบของ Google
- **B. Supabase + GitHub Pages** — เร็วกว่า ปรับหน้าตาได้เต็มที่ ต้องมีหน้าแอดมินแยก
- **ผู้ใช้เลือก B**

## สิ่งที่ผู้ใช้ตัดสินใจแล้ว
- เช็คชื่อด้วยมือถือตัวเองผ่าน QR
- เลือกชื่อจากรายชื่อที่เตรียมไว้ (ไม่พิมพ์เอง ไม่เซ็น)
- Supabase + GitHub Pages
- หลายการอบรมในเว็บเดียว

## สิ่งที่ Claude เสนอ (ผู้ใช้แก้ได้)
- แอดมินล็อกอินด้วย Google (`chaokoh.ex@gmail.com` เท่านั้น)
- ธีมเขียวพาสเทล + ต้นมะพร้าว แต่น้อยลงกว่าเดิม
- repo GitHub ใหม่ชื่อ `training-checkin-lite`, โปรเจกต์ Supabase ใหม่
- ดาวน์โหลดผลเป็นไฟล์ Excel/CSV ได้ต่อการอบรม
- แอดมินยกเลิกการเช็คชื่อที่แตะผิดได้

## หน้าจอ
**1. หน้าผู้เข้าอบรม** (`/?t=<รหัสการอบรม>` — เปิดจาก QR)
```
 🌴 อบรมความปลอดภัยอาหาร
    21 พ.ย. 2569
 [ 🔍 ค้นหาชื่อ...        ]
 ┌──────────────────────┐
 │ สมชาย ใจดี        ✓ มาแล้ว │  (เทา กดไม่ได้)
 │ สมหญิง รักงาน          │
 │ ...                    │
 └──────────────────────┘
 แตะชื่อ → "ยืนยันว่าคุณคือ สมหญิง รักงาน?" [ใช่] [ยกเลิก]
 → หน้าจอ "เช็คชื่อเรียบร้อย ✓ 13:05 น."
```

**2. หน้าแอดมิน** (`/admin.html`, ต้องล็อกอิน)
- รายการการอบรม (ใหม่สุดก่อน) + ปุ่ม "สร้างการอบรมใหม่"
- ฟอร์มสร้าง: หัวข้อ, วันที่, กล่องวางรายชื่อ (บรรทัดละคน — วางจาก Excel ได้)
- หน้ารายละเอียดการอบรม: QR (ขยาย/พิมพ์ได้), ยอด "มา 12 / 20", รายชื่อแยกมา/ยังไม่มา พร้อมเวลา (อัปเดตเองแบบ realtime), ปุ่มดาวน์โหลด CSV, เพิ่ม/ลบชื่อ, ยกเลิกเช็คชื่อ, ลบการอบรม

## ข้อมูล (Supabase)
- `trainings`: id (uuid), title, training_date, created_at
- `attendees`: id (uuid), training_id → trainings, name, checked_in_at (null = ยังไม่มา)
- สิทธิ์ (RLS):
  - คนทั่วไป: อ่าน trainings + ชื่อ/สถานะใน attendees ได้ (ต้องรู้รหัสการอบรมจาก QR)
  - คนทั่วไปเช็คชื่อผ่านฟังก์ชัน `check_in(attendee_id)` เท่านั้น — ตั้งเวลาเฉพาะชื่อที่ยังไม่เช็ค แก้อย่างอื่นไม่ได้
  - แอดมิน (อีเมล `chaokoh.ex@gmail.com`): ทำได้ทุกอย่าง

## เทคนิค
- HTML/CSS/JS ล้วน ไม่มี build step, supabase-js และไลบรารี QR จาก CDN
- โฮสต์บน GitHub Pages
- ภาษาไทยทั้งหมด, ออกแบบสำหรับมือถือก่อน
- ไอคอนใช้ Lucide

## ข้อจำกัด / สิ่งที่ผู้ใช้ต้องทำเอง
- ล็อกอิน Google ต้องตั้ง OAuth Client ใน Google Cloud Console แล้วใส่ใน Supabase (ผู้ใช้ต้องทำเองในบัญชีตัวเอง; ถ้ามี Client เดิมจากตัวก่อน ใช้ซ้ำได้โดยเพิ่ม redirect URL)
- Supabase ฟรีมีโปรเจกต์ที่ทำงานพร้อมกันได้ 2 อัน — ถ้าเต็ม จะใส่ตารางไว้ในโปรเจกต์เดิมโดยใช้ชื่อตารางแยก
- เปิด GitHub Pages ใน repo ใหม่

## ปล่อยให้ผู้สร้างตัดสินใจ
- รายละเอียดการจัดวาง สี และข้อความ
- โครงไฟล์
